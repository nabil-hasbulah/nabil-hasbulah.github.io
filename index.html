DocPrep: multilingual documentation automation suite

Internal tool at Motorola Solutions, Aug – Oct 2026

Problem
Preparing multilingual manual releases involved repetitive manual steps (renaming, merging and packaging files for up to 51 language variants), where small mistakes were easy to make.
Approach
Built a Python desktop suite that standardizes those steps. I took it from idea through beta and pilot to version 1.0, adding pre-flight checks, detailed logs and privacy-conscious adoption tracking.
Result
Release package preparation time dropped by 60%, and HTML packaging by about 80%.

Tools in the suite

  • DocRename
    Batch-renames monolingual PDFs for the release workflow. Co-developed with a teammate.
  • DocMerge
    Merges up to 51 language variants into one bookmarked PDF, with file discovery fallbacks, print-versus-digital cover handling and per-file error isolation.
  • DocPackage
    Packages per-language HTML bundles from Heretto exports with source-structure validation, language detection and consistent ZIP naming. It cut task time by about 80%.

GetSize: manual print-size compliance
